# Scribble — Real-time Collaborative Drawing & Chat App

**Scribble** is a real-time collaborative whiteboard app where multiple users can draw, sketch, and chat together instantly built from scratch using **Nextjs, React, Node.js, WebSockets, and Canvas API**.

## ✨ Features

- 🎨 **Collaborative Drawing Canvas** — Draw in real-time with multiple users  
- 💬 **Live Chat Integration** — Talk while you draw  
- 🧑‍🤝‍🧑 **Multi-user Synchronization** via **WebSockets**  
- 📐 **Shapes, Colors & Eraser Tools**  
- 📝 **Text Tool**  
- 📷 **Add Images into Canvas (PNG)**  
- 🚀 **Persistent Rooms** — Join or create a room with a unique ID  
- 🔒 **Secure Backend**  
- ⚡ **Optimized for Low Latency** using native WebSocket and event throttling
